# Security Policy

## Supported versions

Stoix is currently an early beta. Security fixes are applied to the latest
code on `master`; older builds are not supported.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability or include secrets in
an issue, log, screenshot, or reproduction.

Use [GitHub private vulnerability reporting](https://github.com/finxray/hermes-ui/security/advisories/new)
with:

- a concise description of the issue and its impact;
- affected Stoix version or commit;
- reproduction steps or a proof of concept;
- any suggested mitigation;
- whether and when you plan to disclose the issue.

If private vulnerability reporting is unavailable, email `info@stoix.com` with
the subject `PRIVATE SECURITY REPORT` and omit exploit details from any public
channel.

We will acknowledge a report as soon as practical, investigate it, and
coordinate a fix and disclosure timeline with the reporter.
