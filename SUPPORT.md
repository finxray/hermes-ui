# Stoix Support

Stoix is an MIT-licensed community beta maintained on a best-effort basis. It
does not currently have a response-time guarantee.

## Get help

- Search [existing issues](https://github.com/finxray/hermes-ui/issues).
- Submit a [beta bug report](https://github.com/finxray/hermes-ui/issues/new?template=bug_report.yml).
- Share a [platform test](https://github.com/finxray/hermes-ui/issues/new?template=platform_test.yml).
- Suggest a [focused improvement](https://github.com/finxray/hermes-ui/issues/new?template=feature_request.yml).

Questions or defects in the Hermes runtime itself belong in the
[Hermes Agent issue tracker](https://github.com/NousResearch/hermes-agent/issues).

The source application has received limited maintainer testing on macOS and on
Windows with Hermes inside WSL2. Packaged clean installation has not yet been
validated by the maintainer, and Linux still needs community testing.

For suspected security vulnerabilities, follow [SECURITY.md](SECURITY.md) and
do not open a public issue.
